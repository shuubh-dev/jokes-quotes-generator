# 😂 Jokes & Quotes Generator

A simple React application that fetches and displays random jokes and quotes using APIs.

## ✨ Features

- 😂 Get random jokes
- 💭 Get random quotes
- 🔄 Fetch new content on every click
- 🎨 Simple and clean UI

## 🛠️ Tech Stack

- React
- JavaScript
- CSS
- Axios
- Vite

## 🚀 Run Locally
1. **Clone the repository**
   ```bash
   git clone <your-repository-url>
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start the development server**
   ```bash
   npm run dev
   ```
